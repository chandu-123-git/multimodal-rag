---

### 2. The Indexing Process

The indexing phase prepares the knowledge base and runs once:
1.  **Source Documents** (PDF, TXT, DOC, etc.) are fed into the **Document Loader**, which extracts the raw text.
2.  The extracted text moves to the **Text Splitter**, which breaks it down into **smaller chunks**.
3.  These smaller chunks pass through the **Embedding Model**, which converts the text into **vectors (embeddings)**.
4.  Finally, the vectors, chunks, and their metadata (such as source and page numbers) are stored in the **Vector Store**.

---

### 3. The Retrieval and Generation Process

This phase runs dynamically for each user question:
1.  A **User Question** (e.g., *"What is RAG?"*) is processed by the **Query Embedding** component, which converts the question into a vector.
2.  Using **Similarity Search**, the system queries the **Vector Store** to find the most relevant chunks based on vector similarity.
3.  The system retrieves the **Top-K Relevant Chunks** (along with their metadata).
4.  In the **Build Prompt** step, the user question and the retrieved chunks are combined into a structured prompt.
5.  An **LLM** (such as Gemini) processes this prompt and generates an answer using the provided context.
6.  The output is delivered as a **Grounded Answer** complete with source references (e.g., document name and page).

---

### 4. How the Components Work Together

The two phases connect to form a cohesive pipeline:
*   The **Indexing Phase** establishes a searchable knowledge base offline by ingesting documents, breaking them into chunks, embedding them, and saving them in the **Vector Store**.
*   The **Retrieval & Generation Phase** leverages this stored knowledge online in real-time. When a user asks a question, the query is embedded and matched against the **Vector Store** via **Similarity Search**. 
*   The retrieved context is merged with the user question in the **Build Prompt** stage, supplying the **LLM** with factual reference material so it can generate an accurate, **Grounded Answer** with citations.
